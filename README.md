# BipolarChat — نسخه وب

این بسته نسخه بازطراحی‌شده پیام‌رسان BipolarChat است: رابط فارسی RTL، طراحی روشن الهام‌گرفته از پیام‌رسان‌های مدرن و پالت آبی‌وسفید.

## در این نسخه انجام شده
- تغییر برند رابط کاربری به BipolarChat.
- لوگوی اختصاصی SVG جدید و شفاف در `bipolarchat-logo.svg`.
- بازطراحی صفحه معرفی دامنه اصلی در `main-site.html` با طراحی واکنش‌گرا.
- تغییر رنگ‌های سبز باقی‌مانده از تم WhatsApp به آبی؛ حباب پیام‌های ارسالی آبی روشن است.
- حفظ آدرس پروژه و کلید عمومی Supabase موجود در `config.js`؛ هیچ کلید محرمانه‌ای اضافه نشده است.
- افزایش حداقل رمز عبور حساب‌های جدید به ۱۲ کاراکتر و الزام حروف کوچک/بزرگ انگلیسی و عدد. این تغییر رمز کاربران فعلی را عوض نمی‌کند.
- نگه‌داشتن قابلیت‌های موجود گفت‌وگو، گروه و کانال بدون ادعای اضافه‌کردن قابلیت‌های سمت سرور.

## موارد ضروری پیش از معرفی عمومی
1. در Supabase → Authentication → Providers، تأیید ایمیل را فعال و قالب ایمیل را آزمایش کنید.
2. در Authentication → URL Configuration، `https://web.bipolarchat.ir` را به‌عنوان Site URL و آدرس‌های redirect دقیق موردنیاز را در allowlist وارد کنید.
3. در Authentication → Rate Limits، محدودیت‌های ورود/ثبت‌نام/بازیابی رمز را بررسی کنید؛ محدودیت سمت مرورگر جایگزین این تنظیمات سمت سرور نیست.
4. CAPTCHA را برای ثبت‌نام، ورود و بازیابی رمز در صورت امکان فعال کنید.
5. MFA را برای حساب مالک و حساب‌های مدیریتی فعال کنید.
6. قبل از انتشار عمومی، سیاست‌های RLS جداول و دسترسی Storage را در پروژه فعال Supabase بررسی و با دو حساب آزمایشی (کاربر A و B) تست کنید؛ یک کاربر نباید پیام‌های خصوصی یا فایل‌های کاربر دیگر را بخواند.
7. ورود، ثبت‌نام، خروج، بازیابی رمز، Google OAuth، ساخت گروه/کانال، ارسال پیام و دسترسی از موبایل را روی دامنه واقعی آزمایش کنید.

## قابلیت‌هایی که هنوز نیازمند پیاده‌سازی/تأیید هستند
- استوری با آپلود رسانه، زمان انقضا و کنترل مخاطب.
- تضمین کامل رفتار کانال‌ها و گروه‌ها (عضویت، نقش مدیر، ارسال پیام فقط توسط مدیر کانال، گزارش/مسدودسازی).
- بررسی امنیتی کامل RLS و Storage در پروژه زنده. این موارد از فایل‌های فرانت‌اند به‌تنهایی قابل تأیید نیستند.

## انتشار
- `index.html`, `style.css`, `app.js`, `config.js`, `bipolarchat-logo.svg`, `manifest.webmanifest` را در مخزن/هاست نسخه وب قرار دهید.
- فایل `main-site.html` برای سایت اصلی است؛ برای انتشار در ریشه `bipolarchat.ir` آن را به `index.html` در هاست اصلی تبدیل/کپی کنید.
- دامنه وب `web.bipolarchat.ir` باید به هاست اپ متصل باشد و HTTPS فعال باشد.
- قبل از انتشار، از نسخه فعلی فایل‌ها و تنظیمات Supabase پشتیبان بگیرید.
