# NovaChat Web

رابط وب فارسی NovaChat با طراحی روشن آبی‌وسفید و فونت Vazirmatn. این پروژه تنظیمات فعلی Supabase را در `config.js` حفظ می‌کند.

## انتشار نسخه وب
1. محتویات این پوشه را در مخزن GitHub مربوط به نسخه وب قرار دهید.
2. در GitHub، بخش Settings → Pages را بررسی کنید و منبع انتشار را روی GitHub Actions بگذارید.
3. دامنه `web.bipolarchat.ir` باید در DNS به مقصد میزبانی GitHub Pages متصل باشد و گواهی HTTPS فعال باشد.

## تنظیمات Supabase
`config.js` حاوی URL و کلید عمومی پروژه فعلی است. کلید `service_role` یا هر کلید محرمانه‌ای را در مرورگر قرار ندهید.
اگر ورود خطای شبکه می‌دهد، از داشبورد همان پروژه بررسی کنید که پروژه فعال است، URL/کلید عمومی درست هستند، ارائه‌دهنده Email فعال است و دامنه وب در Authentication → URL Configuration مجاز است. این تنظیمات سمت سرور را نمی‌توان صرفاً از فایل‌های سایت تغییر داد.

## سایت معرفی دامنه اصلی
فایل `main-site.html` یک صفحه معرفی ساده برای دامنه اصلی است. برای میزبانی مستقل سایت اصلی، این فایل و `novachat-logo.png` را در ریشه مخزن/هاست مربوط به `bipolarchat.ir` قرار دهید. فایل `CNAME` این مخزن برای اپ وب روی `web.bipolarchat.ir` باقی می‌ماند.

## اندروید
پیکربندی Capacitor حفظ شده و نام برنامه به NovaChat تغییر کرده است. شناسه برنامه به `ir.novachat.app` تغییر یافته؛ برای انتشار به‌روزرسانی یک اپ نصب‌شده قدیمی، شناسه بسته باید با شناسه نسخه منتشرشده قبلی یکسان بماند.
