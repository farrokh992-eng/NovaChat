# NovaChat v2
Telegram-inspired cross-platform PWA frontend with Supabase Auth, Postgres and Realtime.

## Setup
1. Create a Supabase project.
2. Run `supabase/schema.sql` in SQL Editor.
3. Put the Supabase URL and publishable key in `config.js`.
4. Upload the repository to GitHub.
5. Enable GitHub Pages > GitHub Actions.
